# Projected tunnel

Run `node packages/cli/bin/setcast.js live examples/live-tunnel` from the repository root.
Select the mixer input, move the output to the projector and open Operator window.

The tunnel fills the frame with large, slowly turning geometry: bass breathes the depth and
widens the rings, mids light wall panels and highs add fine rings between the main ones. Its
center stays dark, so the projected light sits on the walls and floor rather than on the booth.
Set `sides: 0` and a small `twist` such as `0.12` for a round vortex, or raise `speed` for a
faster flight. Save variations as scenes and switch them on phrases from the scene pads.

Projector brightness, throw and refresh interaction have not been checked on physical hardware.
